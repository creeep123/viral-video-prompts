# Plan a short video, one shot at a time

Start with a single thing the viewer should notice or understand. Sketch the opening frame, the action that makes the idea clear, and the frame you want to cut on. Use the library prompts as shot briefs you can adapt to your footage.

## Give the opening a job

For a product clip, put a recognisable object or action in the first frame. A hand placing a dented water bottle on a desk gives the viewer something to follow. Show the useful detail in the next beat, then give the result room to register. For a vertical ad, place the subject and text where they stay legible beneath the actual app overlays. TikTok recommends a 9:16 frame with space for its interface and an opening, middle, and close. [TikTok Creative Codes](https://ads.tiktok.com/business/en/creative-codes)

## Match the prompt to the input

| Workflow | What to write |
| --- | --- |
| **Runway image-to-video** | Let the source image establish framing, subject, and lighting. Describe what moves and how. A small product move and a steady camera make a useful first test. Check the start image for motion cues that conflict with the shot. [Runway image-to-video guide](https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide) |
| **Veo 3 text-to-video** | Specify the subject, setting, framing, action, and lighting. If the chosen workflow supports audio, describe the sound separately so you can review it alongside the image. [Google DeepMind Veo prompt guide](https://deepmind.google/models/veo/prompt-guide/) |
| **Seedance 2.0 with references** | Name each input by its role and specify which details to carry through. For a sequence, describe the visible action in each shot in order. Use references you have permission to share and check which inputs your chosen interface accepts. [ByteDance Seedance 2.0 prompt guide](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh&redirect=1) |

An image-to-video starting point for the desk shot could be “A hand sets the bottle upright in the centre of the frame. It settles with a small wobble. The camera holds at desk height, with the bottle sharp against the background.” The start image needs to leave room for the hand and the bottle’s final position.

## Build the cut and check it on a phone

1. **Generate the shots you plan to use.** Keep each shot focused on one action. Cut separate outputs together when an idea needs a change of angle or setting. Add any exact wording or logo overlay in the editor so you can check it before export.
2. **Watch the export at viewing size.** Check the opening frame, motion, cuts, final hold, and placement of any text. Watch once with sound off to see whether the story reads, then listen for unwanted audio and check that any narration stays clear.
3. **Compare one change at a time.** Copy the edit and vary only the opening image, line, or motion. Keep the offer, cut length, and closing frame fixed for that comparison. In a publishing test, record the audience and placement with the results so the two versions can be compared in context.
4. **Record what you actually ran.** Keep the prompt, model version, input, settings, and output together. Note which visible details held up and which need another pass. A prompt with a linked result gives the next editor a useful point of comparison.
